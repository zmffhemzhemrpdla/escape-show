# 🎭 도망자 쇼 (Escape Show)

온라인판 런닝맨/토우소우추우 스타일의 실시간 히든롤 서바이벌 파티게임. 자동 PD가 매 라운드 역할과 미션을 배분해요 — 헌터를 피해 살아남고, 팀 미션으로 헌터를 정지시키고, 숨은 스파이를 조심하세요!

**▶ 플레이: https://zmffhemzhemrpdla.github.io/escape-show/**

- 컴퓨터: WASD/화살표 이동 · Space 액션(스위치·구출)
- 핸드폰: 왼쪽 드래그 이동 · 액션 버튼
- 역할: 🏃 도망자(생존) · 👹 헌터(추격) · 🕵️ 스파이(도망자인 척 미션 방해)
- 잡히면 감옥 → 동료가 구출, 시간 초과 시 탈락

**개발 로드맵**: v1 봇 플레이(현재) → v2 히든롤 확장 → **v3 방 코드 온라인(친구들과 실시간)** → v4 폴리시. 자세한 기획은 [design doc](https://github.com/zmffhemzhemrpdla) 참고.
